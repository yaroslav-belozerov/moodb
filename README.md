## 🏗 Building for Android
```sh  
git clone git@github.com:yaroslav-belozerov/moodb.git
cd ./moodb
./gradlew assembleRelease
```
or download as a [zip file](https://github.com/yaroslav-belozerov/moodb/archive/refs/heads/main.zip)
